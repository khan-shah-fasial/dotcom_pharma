15. Final status

Passed with minor issues

Adding a batch, reading live lots, hiding the purchase rate, saving, converting to a new batch id, and blocking a destroy without a certificate all work. The old ATRODOT row was left as it was. The test rows were removed from the list after the check. The only open item is the heading “P.Rate” versus the sheet’s “P-Rate”.

16. Testing limitations

  • Checked in Chrome only. Firefox, Edge, Safari, and real phones were not used. A narrow Chrome window was used for the phone width.
  • No certificate file was uploaded, so zoom of a real file and a biowaste file upload were not completed. The destroy button correctly refused to continue without that file.
  • The public website was not tested. Debug mode is on in this local setup, which is expected here.
  • Page speed was not measured.
  • A product that already has many purchase rows was not saved, so that heavy save was not repeated on purpose.
